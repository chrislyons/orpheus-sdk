classDiagram
    class SessionGraph {
        +vector~Track~ tracks
        +TempoInfo tempo
        +string sessionName
        +addTrack(Track)
        +removeTrack(id)
        +getTrack(id) Track
    }

    class ITransportController {
        <<interface>>
        +startClip(clipId) ErrorCode
        +stopClip(clipId) ErrorCode
        +stopAllClips() ErrorCode
        +processAudio(buffer, frameCount) void
        +processCallbacks() void
    }

    class TransportController {
        -map~string,ActiveClip~ activeClips
        -IAudioDriver* driver
        -SPSCCallbackQueue callbackQueue
        +startClip(clipId) ErrorCode
        +processAudio(buffer, frameCount) void
        +postCallback(callback) void
    }

    class SPSCCallbackQueue {
        <<ORP121 C-03>>
        -array~function,256~ ring
        -atomic~size_t~ writeIndex
        -atomic~size_t~ readIndex
        +push(callback) bool
        +pop() function
        +isEmpty() bool
    }

    class RoutingConfig {
        <<ORP121 Q-03>>
        +uint8_t numInputChannels
        +uint8_t numOutputChannels
        +uint32_t sampleRate
        +HeadroomMode headroomMode
        +bool enableTruePeak
    }

    class HeadroomMode {
        <<enumeration>>
        <<ORP121 Q-05>>
        None
        PerGroup
        Global
        Logarithmic
    }

    class RoutingMatrix {
        -vector~ChannelState~ channels
        -vector~GroupState~ groups
        -RoutingConfig config
        +setRouting(src, dst, gain) ErrorCode
        +process(inputs, outputs, frameCount) void
        -getHeadroomCompensation(group) float
    }

    class GainSmoother {
        <<ORP121 C-01>>
        -float currentGain
        -float targetGain
        +setTarget(gainDb, rampMs) void
        +process() float
        +MAX_GAIN_DB = 12.0f
    }

    class TruePeakMeter {
        <<ORP121 Q-04>>
        -array~float,12~ history
        -float peakHold
        +process(sample) float
        +getPeak() float
        +OVERSAMPLE_FACTOR = 4
        +TAPS_PER_PHASE = 12
    }

    class SoftKneeLimiter {
        <<ORP121 C-02>>
        +process(sample) float
        +THRESHOLD = 0.794f
        +KNEE_WIDTH = 0.3f
    }

Data Flow ORP121 Lock-free callbacks, true-peak metering, headroom compensation SEQUENCE 
sequenceDiagram
    participant User
    participant UI as UI Thread
    participant Queue as SPSC Queue
    participant Transport as TransportController
    participant Routing as RoutingMatrix
    participant Meter as TruePeakMeter
    participant Audio as Audio Thread
    participant Driver as Audio Driver

    Note over User,Driver: Initialization Phase

    User->>UI: Load Session
    UI->>Transport: new TransportController(session, driver)
    Transport->>Routing: new RoutingMatrix(config)
    Note over Routing: config.sampleRate = 48000
config.headroomMode = Logarithmic
config.enableTruePeak = true
    Routing->>Meter: Initialize per-channel meters
    Transport->>Driver: initialize(config)

    Note over User,Driver: Audio Processing Loop (Audio Thread)

    loop Every Audio Callback (~5ms @ 512 samples)
        Driver->>Audio: Audio callback
        Audio->>Transport: processAudio(buffer, frameCount)

        loop For each active clip
            Transport->>Transport: Read samples from AudioFileReader
            Transport->>Transport: Apply fade IN/OUT curves
            Transport->>Routing: Add to input buffer
        end

        Note over Routing: ORP121 Routing Pipeline

        Routing->>Routing: Step 1: Channel Processing
        Note right of Routing: Apply GainSmoother
Apply constant-power pan

        Routing->>Meter: Step 2: Channel Metering
        Note right of Meter: 4x oversample
48-tap polyphase FIR

        Routing->>Routing: Step 3: Group Mixing
        Note right of Routing: Apply HeadroomMode
(Logarithmic: -10*log10(n))

        Routing->>Routing: Step 5: Master Output
        Note right of Routing: Apply soft-knee limiter
(threshold: -2 dBFS)

        alt Clip reached end
            alt Loop enabled
                Transport->>Transport: Seek to trimIn
                Transport->>Queue: postCallback(onClipLooped)
                Note over Queue: Lock-free push!
            else No loop
                Transport->>Queue: postCallback(onClipFinished)
            end
        end
    end

    Note over User,Driver: Callback Processing (UI Thread, 10Hz)

    UI->>Queue: processCallbacks()
    loop While queue not empty
        Queue-->>UI: callback function
        UI->>User: Update UI state
    end
